# Dreamland Dialogue Studio

Downloads of **Dreamland Dialogue Studio**, the Windows app for writing Dreamland conversations, quests and game logic as node graphs.

## Download

**[Get the latest version](https://github.com/moninja92/dreamland-dialogue-studio-releases/releases/latest)**: download `DreamlandDialogueStudio-…-windows.zip` under **Assets**.

1. Unzip it into its own folder.
2. Run **DreamlandDialogueStudio.exe**. Nothing is installed.
3. The first time, Windows may say it protected your PC, because the app is not code-signed. Choose **More info**, then **Run anyway**.

Each release lists what changed and the dialogue runtime version the game needs.

## Getting started

- **Help > Walkthrough** shows each part of the screen.
- **Help > Tutorial** and **Help > Training** teach conversations, variables, checks and quests.
- **Game > Link game project** connects Studio to the Dreamland game folder so you can publish.

## Updating

Download the newest zip and replace the old exe. Your drafts and settings are kept; they are stored separately from the app.

## Problems or ideas

In Studio, use **Help > Report a bug or suggestion**.
